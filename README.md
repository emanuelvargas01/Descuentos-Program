
# Laboratorio #1 Pract2- Descuentos
**Fecha:** [25/09/2026]

## Contenido del Repositorio
Este laboratorio incluyo la aplicacion de conceptos basicos de interfaz dentro de C# utilizando Visual Studio en la que se hizo un formulario para calcular el descuento de una compra, aplicando diferentes porcentajes de descuentos segun limites establecidos en compras.
